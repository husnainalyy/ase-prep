# Day 1 — OS

**Topic:** Fundamentals

---

## 1. What is an Operating System?

### Answer

An operating system is the main program that runs the computer. It manages the hardware and gives every other program a safe way to use it.

- It sits between you and the hardware. You do not talk to the processor or the disk yourself.
- It shares the CPU, memory, storage, and devices among the programs that are open.
- It starts programs, stops them, and keeps one program from breaking another.
- Windows, Linux, macOS, and Android are operating systems.
- A browser, a game, and a compiler are applications. They run on top of the operating system.

### Interview

An operating system is the software that manages the computer's hardware and lets applications use it. It controls the CPU, memory, files, and devices, and it keeps programs from interfering with each other. Windows, Linux, and macOS are operating systems. Chrome and a game are applications that run on top of one.

#### Example

You double-click a file. The operating system finds the file on the disk, loads the right program into memory, gives it CPU time, and shows the window. The program never moves the disk head or paints the screen by itself.

---

## 2. What are the main functions of an Operating System?

### Answer

The operating system has a small set of jobs. Each job looks after one part of the computer.

- **Process management:** starts programs, gives them CPU time, and switches between them.
- **Memory management:** gives each program memory and takes it back when the program ends.
- **File management:** creates, reads, updates, and deletes files and folders on the disk.
- **Device management:** controls the keyboard, mouse, printer, disk, and screen through drivers.
- **Security:** checks who is logged in and what that user is allowed to open or change.
- **The interface:** a desktop or a terminal so a person can give commands.

### Interview

The main jobs are process management, memory management, file management, and device management. The operating system also checks users and permissions, and it gives a desktop or a terminal so a person can run programs. These jobs share the hardware and keep programs from colliding.

#### Example

You open a browser and a music player together. The operating system gives each one some memory, switches the CPU between them, reads their files from the disk, and sends sound to the speakers. You only see two windows.

---

## 3. What are the different types of Operating Systems?

### Answer

Operating systems are grouped by how they run programs and who uses them.

- **Batch:** jobs are collected and run one after another, with no person waiting at the screen. Old payroll runs worked this way.
- **Time-sharing:** many people or programs share one computer. Each gets a short turn on the CPU, so it feels simultaneous. Linux and Windows do this.
- **Real-time:** a reply must arrive before a deadline. A car brake controller and a medical monitor use this.
- **Distributed:** several computers work as one system and share the work. A large website's servers do this.
- **Mobile:** built for phones and tablets, with a touch screen and tight battery use. Android and iOS are mobile operating systems.
- Memory line: batch is a queue, time-sharing is turns, real-time is a deadline, distributed is many machines, mobile is a phone.

### Interview

A batch operating system runs collected jobs one after another. A time-sharing system gives many programs short turns on the CPU, which is what Windows and Linux do. A real-time system must answer before a deadline, as in a car controller. A distributed system joins several computers so they work as one. Android and iOS are mobile operating systems made for phones.

#### Example

A bank can use more than one kind on the same day. Overnight salary calculation is a batch job. The teller's computer, shared by many programs, is time-sharing. The ATM must answer in a fixed time, so that part is real-time. The bank's many servers together are a distributed system.
