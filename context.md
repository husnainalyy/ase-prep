# Answer format

Read this file before writing any answer. DSA and OOP use different orders. Use only the order for that subject.

# DSA

## 1. Explanation

After `### Answer`, add a heading `### Explanation`.
Leave two lines under it for the explanation. Do not type `&emsp;` or `<br>`.
The first line is two em spaces. The second line is one non-breaking space.
Those characters look blank, stay visible in preview, and survive format on save.

## 2. Approach

Write the idea in simple English as bullet points.
Use dots, not a numbered list.
Use at least 3 bullets.
No variable list, no step-by-step loop, no dry-run table, and no output section.

## 3. Pattern

One sentence that names the pattern.

**Pattern:** The two pointers pattern is used.

## 4. Complexity

**Time complexity:** O(n)

**Space complexity:** O(1)

## 5. Code

Put the solution in a fenced code block under `### Code`.

## Shape

### Answer

### Explanation

  

 

**Approach**

- First point of the idea.
- Second point of the idea.
- Third point of the idea.

**Pattern:** The pattern name pattern is used.

**Time complexity:** O(n)

**Space complexity:** O(1)

### Code

A fenced code block with the solution.

# OOP

For each question, use this order: answer, bullet points, then an Interview heading with an Example subheading.

## 1. Answer

After the question, keep `### Answer`.
Leave two lines under it for the written answer. Do not type `&emsp;` or `<br>`.
The first line is two em spaces. The second line is one non-breaking space.
Those characters look blank, stay visible in preview, and survive format on save.

## 2. Bullet points

Write the main points as dots, not a numbered list.
Use at least 3 bullets.
Put them directly under the answer space.

## 3. Interview

Add `### Interview`.
Leave the same two lines under it: two em spaces, then one non-breaking space.
Then add `#### Example`.
Put the example in a fenced C++ block under Example.

## Shape

### Answer

  

 

- First point.
- Second point.
- Third point.

### Interview

  

 

#### Example

A fenced code block with the example.
